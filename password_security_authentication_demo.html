Security recommendations

  • Never store plaintext passwords.
  • Production systems should use Argon2id, bcrypt or scrypt with suitable settings and unique salts.
  • Use HTTPS, server-side validation, secure session handling and rate limiting.
  • Do not use this browser-only demo to protect real accounts or real passwords.
